System Architecture

Labs and knowledge live in the same student space

The architecture below turns the current prototype into a course shell: the hub routes students into each lab, each lab links into the knowledge database at the moment of need, and the database links back to active labs and reusable concepts.

Implementation Model

Static First, LMS Ready Later

The current build can run as a static site on GitHub Pages, a school server, or an LMS content page. Student work remains local in the browser unless the school later connects an approved LMS/LTI workflow.
