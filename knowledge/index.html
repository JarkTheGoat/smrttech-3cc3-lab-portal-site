LabVIEW Reusable topic

Front Panel and Block Diagram

The front panel is the student-facing interface: controls, indicators, labels, and decorations. The block diagram holds the terminals, functions, structures, wires, and execution logic.

Lab connection

Use this when building the voltage-divider VI and deciding what belongs on the interface.

LabVIEW Reusable topic

Controls and Indicators

Controls provide input values to a VI. Indicators display output values produced by the VI. In the divider VI, Vin, R1, and R2 are controls; Vout is an indicator.

Lab connection

Quick check: a Stop button is a Boolean control because it supplies a value to the loop condition.

LabVIEW Reusable topic

VI and SubVI

A VI is a LabVIEW program. A VI becomes a SubVI when it is given a connector pane and reused inside another block diagram.

Lab connection

A future lab can package the voltage-divider calculation as a reusable SubVI.

LabVIEW Reusable topic

Data Types, Arrays, and Clusters

Numeric wires carry numbers, Boolean wires carry true or false, and strings carry text. Arrays hold multiple values of one type. Clusters group related values and may combine different types.

Lab connection

Five voltage readings naturally form an array; a student ID plus readings plus a completion flag could form a cluster.

LabVIEW Reusable topic

While Loops, For Loops, and Shift Registers

A while loop repeats until a stop condition is met. A for loop repeats a known number of times. A shift register carries a value from one iteration to the next.

Lab connection

The LabVIEW exercise uses a while loop so the calculation can continue until the user stops it.

Circuits Reusable topic

Voltage Divider

A voltage divider uses two resistors to create an output voltage that is a fraction of the input voltage: Vout = Vin * R2 / (R1 + R2).

Lab connection

Before calculating, identify which resistor is between the output node and ground.

Circuits Reusable topic

Photoresistor

A photoresistor is a light-dependent resistor. Its resistance changes with illumination, which makes it useful as the sensing element in the automatic lighting system.

Lab connection

The divider turns resistance change into voltage change so the Arduino can read it.

Circuits Reusable topic

Breadboard and Trainer Board

A breadboard connects holes in internal rows and power rails. A trainer board adds a controlled supply and other lab resources.

Lab connection

Verify rail continuity and common ground instead of assuming every board matches the picture.

Circuits Reusable topic

Resistors and LED Polarity

The divider uses a 4.7 kOhm resistor. The LED path uses 220 ohm to limit current. An LED is polarized, so orientation matters.

Lab connection

A reversed LED may stay off; an LED without current limiting can be damaged.

Measurement Reusable topic

Multimeter Modes

Use resistance mode on an unpowered circuit or isolated component. Use voltage mode on a powered circuit with the meter placed in parallel between the node and ground.

Lab connection

Current mode is not required for the provided labs.

Measurement Reusable topic

Calculated Versus Measured Values

Calculated values assume ideal components and controlled conditions. Measured values include tolerance, sensor variation, supply variation, meter accuracy, and contact resistance.

Lab connection

Percent difference = abs(measured - calculated) / abs(calculated) * 100%.

Arduino Reusable topic

Analog Input and Digital Output

Analog input A0 reads a range of voltages as a number. Digital pin 7 commands the LED as LOW or HIGH.

Lab connection

Use A0 for the sensor voltage and D7 for the LED state.

Arduino Reusable topic

Arduino Code Flow

setup() runs once. loop() repeats continuously. analogRead() samples the sensor. digitalWrite() controls the output. if/else selects the LED action.

Lab connection

If PR is below lowLightLim, the given code writes HIGH to LEDPin.

Simulation Reusable topic

Tinkercad Circuits

Tinkercad lets students construct, measure, and program the circuit before using physical hardware.

Lab connection

Simulation is a model. It helps find logic and wiring errors, but the real circuit still needs bench verification.

Practice Reusable topic

Circuit Troubleshooting Sequence

State expected behavior, remove power before rewiring, verify supply and ground, trace one signal path, measure intermediate nodes, change one thing at a time, and retest.

Lab connection

Use this sequence before replacing parts or rewriting working code.
