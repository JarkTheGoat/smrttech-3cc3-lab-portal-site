Lab 2: Temperature Sensing with LabVIEW and Arduino

A guided interactive companion for Lab 2: build a Celsius-to-Fahrenheit VI, convert it into a SubVI, read a thermistor divider through Arduino A0, and display live temperature in LabVIEW.

Software: LabVIEW + LINX Hardware: Arduino Mega + thermistor Core concept: resistance to voltage Deliverables: VIs, evidence, Kelvin extension

Scenario

Build the local sensing layer of an IoT system

Central question

How does a change in physical temperature become a live digital temperature display in LabVIEW?

You are building the first sensing node for an Internet of Things temperature-monitoring system. Before data can be sent to the cloud, the local system must correctly sense temperature, convert a physical change into voltage, acquire that voltage using Arduino, and display a meaningful temperature value in LabVIEW.

This lab focuses on the local sensing layer, not yet the cloud layer.

Temperature changePhysical condition changes.
Thermistor resistanceThe sensor resistance changes.
Divider voltageA voltage appears at the junction.
Arduino A0Analog input reads voltage.
LabVIEW LINXVoltage data enters LabVIEW.
ConversionA model infers temperature.
DisplayCelsius, Fahrenheit, or Kelvin appears.

LabVIEW does not directly measure temperature. Arduino reads a voltage, and LabVIEW uses the course-provided thermistor conversion VI or instructor-provided sensor parameters to infer temperature.

Checkpoint 2

Build a basic temperature-conversion VI

Create a LabVIEW VI that converts degrees Celsius to degrees Fahrenheit. Save it as Convert C to F.vi.

How to build it: Front Panel
  1. Open LabVIEW and create a blank VI.
  2. Add a numeric control labelled deg C.
  3. Add a numeric indicator labelled deg F.
How to build it: Block Diagram
  1. Use Multiply, Add, numeric constant 1.8, and numeric constant 32.0.
  2. Wire the Celsius control through F = 1.8C + 32.
  3. Run the VI with several values before trusting it.

Checkpoint 3

Turn your conversion into a reusable SubVI

Reopen Convert C to F.vi and convert it into a SubVI. A SubVI is a reusable block that hides internal details while exposing defined inputs and outputs.

Step-by-step SubVI procedure
  1. Save a backup copy of the working Celsius-to-Fahrenheit VI.
  2. Open the VI front panel and confirm the control is named deg C and the indicator is named deg F.
  3. Open the icon editor and create a simple, readable icon that communicates C to F conversion.
  4. Open the connector pane and choose a two-terminal pattern.
  5. Assign the left terminal to deg C and the right terminal to deg F.
  6. Turn on Context Help and hover over the SubVI icon to confirm the terminals are labelled correctly.
  7. Save the SubVI, then place it in a new test VI and verify 0, 25, and 100 degrees Celsius.

Core actions

  1. Edit the VI icon and make it represent C to F.
  2. Choose a connector pane pattern with two terminals.
  3. Assign the left terminal to deg C.
  4. Assign the right terminal to deg F.
  5. Use Context Help to verify the terminals.
  6. Save the VI.

Regular VI versus SubVI

Regular VI
  • Built and run directly
  • Front panel visible to the user
  • Contains full block diagram
SubVI
  • Used as a block inside another VI
  • Has defined input and output terminals
  • Encourages modular design and reuse

Checkpoint 4

Build and verify the thermistor voltage-divider circuit

Build the thermistor voltage-divider circuit using the thermistor, 10 kΩ resistor, Arduino Mega, breadboard, jumper wires, 5 V, GND, and A0.

Skill map references

  • Voltage divider

Build focus

Use the instructor-provided schematic and bench hardware to identify the thermistor, fixed resistor, 5 V, GND, and the divider junction that feeds Arduino A0.

Sketch your own wiring map before powering. The goal is to understand the signal path rather than copy a picture.

Confirm placement before power. Confirm the exact thermistor and resistor placement with your instructor or the course-provided schematic before powering the Arduino. Reversing the thermistor and fixed resistor may reverse the temperature-voltage relationship.

Safe recovery sequence

If the reading is missing or implausible, disconnect USB power before moving wires. Verify 5 V, GND, the A0 divider junction, thermistor seating, and the 10 kΩ resistor row; then confirm LINX firmware, serial port, and analog channel 0. Change one item at a time and retest with a measurement or inspection.

  • What would happen if 5 V and GND were accidentally shorted?
  • Why might touching the thermistor change the reading slowly rather than instantly?

Checkpoint 5

Read the sensor through LabVIEW LINX

Create a main VI that opens a LINX connection, reads Arduino analog channel 0, sends the voltage to the course-provided thermistor conversion VI, reuses your C-to-F SubVI, lets the user select Celsius or Fahrenheit, displays the result on a thermometer indicator, repeats inside a while loop, stops with a Stop button, and closes LINX after the loop ends.

Arduino A0 voltage->LINX Analog Read->Thermistor voltage-to-Celsius VI->C-to-F SubVI->Select scale->Thermometer display
A. Front Panel

Add temperature scale switch, thermometer indicator, serial port control or constant, and Stop button.

B. Block Diagram

Organize dataflow left to right: open, read, convert, select, display, close.

C. LINX Connection

Use LINX Open with the Arduino serial port. Keep it outside the while loop.

D. Analog Read

Use LINX Analog Read with Analog Channel constant set to 0.

E. Temperature Conversion

Use the course-provided thermistor conversion VI or instructor-provided sensor parameters.

F. Unit Selection

Use your C-to-F SubVI and a Select function controlled by the Temp Scale switch.

G. While Loop

Place repeated measurement and display code inside the loop so data updates live.

H. Safe Stop And Close

Wire the Stop button to the loop condition and place LINX Close after the loop.

I. Run And Observe

Run the VI, touch or warm the thermistor, observe response, then stop with the Stop button.

Glossary

Key terms

Thermistor
A resistor whose resistance changes with temperature.
Resistance
Opposition to electric current, measured in Ω.
Voltage divider
Two resistive elements that create a measurable junction voltage.
Analog voltage
A continuously varying voltage value.
Arduino analog input
A microcontroller input that measures voltage and converts it to a number.
A0
Analog input channel 0 on the Arduino.
ADC
Analog-to-digital converter.
LabVIEW
A graphical programming environment.
VI
Virtual Instrument, a LabVIEW program.
Front Panel
The user-facing controls and indicators of a VI.
Block Diagram
The graphical program logic of a VI.
Control
A LabVIEW input object.
Indicator
A LabVIEW output display object.
SubVI
A reusable VI used as a block inside another VI.
Connector pane
The terminal mapping that defines SubVI inputs and outputs.
LINX
LabVIEW toolkit for communicating with supported hardware such as Arduino.
Serial port
The communication port used by the computer to talk to Arduino.
While loop
A repeated LabVIEW structure that continues until a stop condition is met.
Stop button
A controlled way to end a running VI.
Abort button
An emergency stop that can interrupt cleanup logic and should not be the normal stop method.
Celsius
A temperature scale based on water freezing at 0 and boiling at 100 under standard conditions.
Fahrenheit
A temperature scale where F = 1.8C + 32.
Kelvin
An absolute temperature scale where K = C + 273.15.
Calibration
Relating measured signals to meaningful physical values.
Sensor noise
Small variation in readings caused by circuit, environment, or measurement limits.
Settling time
The time required for a sensor reading to approach a new stable value.
IoT sensing node
A local device that senses a physical condition and can later send data to a network or cloud system.
